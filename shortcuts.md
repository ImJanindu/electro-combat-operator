## Keyboard shortcuts currently set up for the Operator dashboard and their functions

### Timer & General Controls
- `S` : **Start match** (Available when idle and both teams are selected).

- `Spacebar` : **Pause / Resume** timer toggle.
- `+` : **Add 1 second** to the match timer.

- `-` : **Reduce 1 second** from the match timer.

- `Enter` : **Emergency Stop** (Triggers emergency stop during an active match).

### Recovery Controls
- `Shift` : **Toggle recovery target** between Team A and Team B.

- `Backspace` : **Trigger Recovery** countdown for the targeted team. Pressing it again will **Resume** the match from recovery.

### Match Resolution 
*(These are only active after the match timer ends or the match is stopped)*
- `A` : Declare **Team A** the winner.
- `B` : Declare **Team B** the winner.
- `D` : Declare a **Draw**.
- `R` : **Reset / Cancel** the resolution state.

### Post-Match Controls
*(These are only active in the post-match state)*
- `I` : **Return to Idle** (Resets the timer and clears selected teams).
- `L` : **Show Leaderboard**.

*(Note: Shortcuts are intentionally disabled if you are actively typing inside a text input or dropdown).*
